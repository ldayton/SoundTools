# Central genres and Country exploration

Branch `experiment/genre-country`, based on approved main `aff1d47`. This does not
include the separately committed, unapproved acoustic-space experiment.

## Representation and engine

`backing-genres.ts` owns genre IDs (derived from the registry), display names,
meter, advisory preferred tempo/range, harmonic cycles, groove strategy,
subdivision, instrument roles and anchor beats, articulation vocabulary, shared
bass-density policy, long-form sections, activity policies, and default sound/mix
preset identity. UI choices, persisted style validation, chord lookup, generated
Country form and transport form length all consume this definition.

`genreBackingArrangement` is the common production entry point. It dispatches to
one of two explicit musical strategies and then applies the approved drum
articulation, guitar-transition and shared-pocket layers. Genre rules remain
separate from sample selection, mix gains and room processing. The existing
approved electric band is the only implemented sound preset in this experiment;
the descriptors provide a place to introduce other supported instrument presets.
Preferred tempo is advisory and does not overwrite the user's selected BPM.

Blues/Rock keep their authored human-performance strategy and detailed groove
catalogue. Their exact chord definitions have moved to the registry, and their
section metadata is read centrally from the same catalogue. Their detailed
performance dynamics, accents and fill choreography remain authored data rather
than being reduced to a few generic numeric knobs. The historical rendering
paths remain available. This intentionally preserves their approved behaviour.

Country demonstrates the generated strategy: its progression, anchor patterns,
bass/guitar rhythm, phrase length, fill cadence and section envelope consume the
registry directly. A future genre can reuse a compatible strategy or introduce a
new one; a new name with arbitrary constants is not assumed sufficient for every
musical style. All implemented genres are 4/4; other meters need transport/strategy
work before being exposed.

## Country behaviour

A clean-electric two-step with bass on beats 1/3 and quiet chord support on 2/4.
The major progression includes I, IV, vi and V. The minor variant stays inside the
natural minor parent scale, using i, VII, VI, iv and v colours. The scale exercise's
selected tonic/quality controls accompaniment as for Blues and Rock.

Bass has exactly two attacks per bar, alternating root/fifth with an occasional
phrase-ending chord-tone substitution. Activity never increases bass density.
Steady and Active differ in restrained drum fills and guitar articulation length.
Guitar plays supporting chord shells/occasional full triads, not a lead line.
Playable concert-key voicings reuse the approved cyclic voice-leading strategy.

A 64-bar form moves through Opening (8), Settled (16), First lift (16), Pull back
(8), Return (8), Home (8). The end returns to the opening energy. Per-loop phrase
memory changes restrained chord-tone choices and energy; transport loops on the
256-beat boundary. WAV previews include two seconds of release after the story;
that preview tail is not part of the app's loop period.

No new sample downloads, software installs or proprietary assets. Existing clean
Black and Green Guitar, Black and Blue Bass and Virtuosity Drums recordings are
used with the approved instrument gains and room. Country is newly composed,
so its instrument density and rhythm naturally differ from Blues/Rock.

## Preservation and validation

Before editing, 224 approved full-take JSON fingerprints were captured at
`aff1d47`, covering Blues/Rock, both modes, both qualities, every tonic, two loop
cycles, and 72/90/120 BPM cases. The centralized engine reproduces every SHA-256
exactly, including event timing, pitches, velocities, durations and metadata.
The fixture is a frozen pre-refactor oracle, not generated by the new engine.

182 unit tests pass. Country is checked in every major/minor key and both modes
for sparse bass, four-plus pitch classes per pitched instrument, playable string
positions, scale-safe notes, 64-bar bounds and matching seam energy. Existing
physical voice, harmony and pocket tests pass. TypeScript and production build
pass. Separate Country and approved Blues/Rock browser playback checks pass for
selection, key reload, mode/tempo changes, loop cycles, physical chokes, working
sample memory and metronome phase.

## Reproduce

- `npm test --workspace=@ldayton/music-practice`
- `npm run build --workspace=notewise`
- `node_modules/.bin/tsc -p apps/notewise/tsconfig.json`
- `npm run test:backing-realism --workspace=notewise`
- `npm run test:backing-genres --workspace=notewise`
- `node_modules/.bin/tsx scripts/render-country-previews.mts OUTPUT`
- `python scripts/match-backing-ab.py OUTPUT`

The WAVs use the actual app sampler/mix: full 64-bar Country stories at 104 BPM,
A major and A minor, Steady/Active, stereo 48 kHz/24-bit. One constant gain per
file matches loudness; no limiting or rolling normalization. Instrument recording
credits remain in app Settings/asset NOTICE files; Country composition is original.
